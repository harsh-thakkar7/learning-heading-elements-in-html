# Learning Heading Elements in HTML

An HTML project exploring heading elements (`<h1>` to `<h6>`) along with unordered lists (`<ul>`) and ordered lists (`<ol>`) through a fun cinnamon rolls recipe page.

## What You'll Learn

- HTML heading hierarchy (`<h1>` through `<h6>`)
- Unordered lists (`<ul>` and `<li>`)
- Ordered lists (`<ol>` and `<li>`)
- Combining headings with list elements

## How to Run

1. Clone this repository
2. Open `index.html` in your browser
